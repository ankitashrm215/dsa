**Sets in Python:** Sets in Python are a data type that sits somewhere between lists and dictionaries, combining some of the advantages of both. They store unique values and provide fast membership testing—checking whether an item exists in a set takes O(1) time on average. Unlike dictionaries, sets do not store key-value pairs; each user input acts like a “key” with the address decided by the interpreter being the value. If you try to add a duplicate element, the set automatically ignores it, keeping only one copy without raising an error.
